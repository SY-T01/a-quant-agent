# 程序与命令入口

日常使用根目录“股票研究助手.app”。应用本质上是本项目统一入口的Mac应用封装，调用系统Terminal运行中文菜单，无需安装额外依赖；不可脱离项目单独移动。

开发时可使用：

```sh
python3 -B -m stock_selector.launcher
python3 -B -m stock_selector.launcher --action view
python3 -B -m stock_selector.launcher --action health
python3 -B -m stock_selector.launcher --action update
python3 -B -m stock_selector.launcher --action ai
python3 -B -m stock_selector.weekly --cached
python3 -B -m unittest discover -s tests -q
```

统一入口的位置解析固定在代码所属项目，不依赖启动终端所在目录。view只打开已存在的报告；update调用带测试、归档和回滚保护的weekly流程；health不联网；ai仅将密钥传给本次子进程，不写入配置。菜单中取消操作可回到主菜单。

原有后台模块入口保留，包括sector_research、weekly、health、quotes、ingestion和原短周期演示CLI，周一自动任务无需修改。原始Word设计方案保留在根目录。具体数据口径及未验证事项见同目录使用指南和自评报告。
