# 按计划资金生成分配建议

1. 打开股票研究助手.app，菜单8设置持有期。
2. 菜单9输入本次计划投入的新资金，例如100000或10万。支持1元至10亿元，金额最多两位小数；不代表完整家庭资产，也不含已有持仓。
3. 选择保守、均衡或积极的分配风格。设置与持有期一起保存在外置磁盘项目的configs/research_preferences.json，修改其中一项会保留其他设置。保存设置仅刷新本地报告，不调用API。
4. 菜单4调用一次DeepSeek，同时生成逐股意见、条件情景和资金分配，按原流程消耗API额度，不自动重试。

|风格|单股上限|单行业上限|现金下限|
|---|---|---|---|
|保守|15%|30%|40%|
|均衡|20%|35%|25%|
|积极|25%|40%|10%|

这些是程序研究约束，不是最优仓位证明或个人风险承受能力评估；不根据金额大小自动推定风格。行业按已有供应商分类归并，跨行业共同风险仍需分析。

## 报告展示

当前可考虑的条件分配：只允许本期有条件通过且计划完整的股票，仍要满足开始条件。若没有通过的股票，程序明确保留全部资金为现金，不伪装成模型已经给出了新建议。

条件满足后的备选分配：可以分析暂缓股票在阻断项解除后值得预留多少资金，并说明条件；不纳入被否决、漏审、引用无效的股票。两个方案使用的是同一笔预算，不是两笔新增投资，不可相加执行。

模型给比例和理由，程序把比例换算成元，向下保留两位小数，尾差留在现金中，确保股票与现金金额之和等于预算。通过股票的分批比例沿用已检查的逐股计划，再换算为分批金额。备选方案不生成当前执行分批。

金额是预算预留，不是成交股数。会按报告参考价核对最低买入金额：主板/创业板按100股，科创板按200股；参考依据为[深交所主板交易机制说明](https://investor.szse.cn/institute/rules/t20230706_601604.html)和[上交所科创板投教问答](https://edu.sse.com.cn/tib/qa/)。预算不足时拒绝该资金方案，不向上补钱或假装买入碎股。没有依据实时价格、交易权限和费用生成委托，不能把预算金额直接视为可成交订单。

组合附带人为设定的压力情景：假设所配股票同步涨跌20%，计算账面盈亏及其占总预算的比例，现金保持不变；忽略费用与分红，不作概率或收益预测。

## 异常与每周更新

资金方案单独检查未知或重复股票、引用、结论、数字、比例合计、单股/行业上限及现金下限。当前方案和备选方案分别核对，坏方案不会抹去有效逐股意见或另一个有效方案。

资金金额、风格、持有期与证据共同参与资金方案的匹配。仅修改金额或风格不会使逐股意见失效，但需要按新设置取得新的资金方案；不把旧比例自动改成新的模型建议。已保存响应可离线重新处理，匹配原设置的方案才能恢复为本期意见。

每周任务沿用保存的资金与持有期。有环境密钥时，在原来的一次DeepSeek调用内生成资金分配；没有密钥不调用付费服务。报告输出包括网页、Markdown和PDF。
