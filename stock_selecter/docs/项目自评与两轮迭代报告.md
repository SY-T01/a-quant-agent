# 项目自评与两轮迭代报告

本次评估的结论是：项目可用于整理行业资金、公开季报与条件股票清单；尚不能据此认定3—6个月选股策略有效。两轮迭代已实际修改程序并通过验证，重点是可复现性、数据保护和使用体验，没有通过调权制造更好的收益结果。

## 评估方法与实际基线

评估对象为当前代码、已保存的真实数据、运行日志和回归测试。本次没有重新下载市场数据，没有调用收费AI，没有执行交易。使用的资金与行情源时间仍为2026年11月6日；本次生成的新报告时间不代表市场数据更新。

基线：46项测试；496个多层级板块；5577家公司利润表与5577家现金流表；128个板块通过代码和名称匹配；1714条盈利且收入利润双增长线索；28只通过初步财务条件的行情候选；5只条件研究候选。行业历史接口最终成功覆盖为0，因此当前没有实际中期行业趋势与样本外收益验证。

|维度|迭代前判断|主要证据与缺陷|两轮完成后的判断|
|---|---|---|---|
|实用性|研究辅助可用|资金、盈利、现金流可追溯，但前30只取样受输入顺序影响，缺乏门槛敏感性说明|候选池按行业轮流核验、排序固定；明确展示覆盖范围、评分分解和两类门槛敏感性。仍为研究工具|
|可靠性|工程基础具备，关键保护不全|缓存直接写入；财报未来日期和无时区输入未完整保护；周报直接覆盖正式目录；无长期收益验证|增加原子缓存、时间门槛、完整报告发布回滚、源时间倒退保护、原始快照校验和失效锁自动释放；投资可靠性仍待验证|
|便利性|能运行，但操作混杂|查看报告会启动联网更新，错误集中在日志里，异常退出可能留下锁|提供离线查看、周更新、自检三个入口；运行状态直接显示；失败保留旧报告，归档与错误记录独立保存|

以上采用定性判断，没有给出缺乏真实样本支持的收益率或“可靠性百分比”。

## 第一轮 已完成 可靠性与可复现性

1. 将取列表前30只改为按行业轮流取样，行情核验上限120只；同行内部以明确质量排序，证券代码作固定并列排序。反转输入顺序不改变取样结果，冲突的同一证券记录会停止推荐。
2. 补齐财报报告期在未来、披露日期缺失或尚未可用、行情时间缺失或无时区等门槛。日期错误只排除对应候选，不再让无效时间进入推荐。
3. 缓存改为同磁盘临时文件完整写入、刷新后原子替换。模拟磁盘发布失败时旧缓存仍可读取，临时文件自动清理。
4. 输出现金流、增长、估值、行业资金四项评分贡献，能够核对总分。
5. 对固定已核验行情池进行两种敏感性检查：PE上限从45降到36；现金流覆盖下限从0.8升到1.0。它们是稳健性观察，不是收益优化。

第一轮结果：53项测试通过。当前1714条公司线索中，28只通过初步财务与行业条件，28只都有行情缓存；两种门槛变化下原5只均保留。因为本次初筛仅28只，新120只上限没有扩大实际覆盖，不将工程改动包装成增加了数据量。

记录：reports/self_review/round1.json。

## 第二轮 已完成 发布保护与日常使用

1. 新增“打开最新报告.command”：正常查看不联网、不重新抓取季报。
2. 新增“运行周更新.command”：先测试、归档、暂存生成，再发布完整报告。更新发生异常时保留当前正式报告，并在当次周目录写failure.json和日志。
3. 新增“项目自检.command”：检查资金源时间、财报覆盖、行情覆盖、历史缺口和报告引用的原始数据校验值。自检只报告数据和工程状态，不把测试通过解释成策略有效。
4. 发布时要求HTML、研究JSON及Markdown均存在且行业列表非空。模拟新报告目录替换失败时，旧报告自动恢复。
5. 源时间倒退不算新数据，并阻止发布；资金快照或财报覆盖失效时暂停新增推荐。
6. 周任务改用操作系统文件锁，进程异常退出后自动释放，留下锁文件也不再阻塞下一次运行。重复任务仍会被阻止。测试超时上限3分钟，数据更新进程30分钟。
7. 报告显示运行状态与门槛敏感性，原始数据清单包含板块、财报、基准和候选行情来源。

最终结果：63项测试通过。已实际跑通缓存周报流程，完成暂存、发布、前后归档和对比，正确标记“没有新板块快照”；31份被当前报告引用的原始快照SHA256校验全部通过。它们是工程验证结果，不是实盘或投资绩效验证。

记录：reports/status/health.json、reports/self_review/round2.json以及reports/weekly/下本次运行目录。

## 尚未解决的实质问题

- 行业历史接口不稳定，当前无法用真实完整序列验证63/126交易日结果。需要可靠长期历史数据后再做滚动样本外检验及费用、滑点测试。
- 行业板块存在父子层级重叠，行业上限目前按板块代码计数，不等同按产业链风险完成分散。
- 行情PE字段口径尚未通过独立数据源核实；ST名称与最近成交也不能代替完整实时交易状态和公告检查。
- 未接入个人持仓、资金规模和风险承受能力，当前股票清单不是个性化组合。

后续最有价值的工作应是解决这些数据与验证问题，而不是继续增加不受检验的评分因子或让AI凭空给出目标价。
