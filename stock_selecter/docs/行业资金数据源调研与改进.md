# 行业资金源调研与改进（2026-11-10）

结论：东财快照当前仍断连；已接入可直接访问的同花顺公开行业资金表作为独立观察补充，不能把它宣称为东财主榜已恢复或已完成跨源选股替换。

## 调研证据

- AKShare [资金流源码](https://github.com/akfamily/akshare/blob/main/akshare/stock/flow/stock_fund_em.py)仍调用东财push2；切换封装库不产生独立数据源。
- AKShare [统一连接处理](https://github.com/akfamily/akshare/blob/main/akshare/utils/http.py)记录东财断连后的反复重试问题并立即停止；这支持采用冷却策略，不足以证明本机断连一定由限流造成。
- [efinance](https://github.com/Micro-sheep/efinance)的资金数据同样依赖东财，不作为独立灾备。
- [mootdx](https://github.com/mootdx/mootdx)及[pytdxdata](https://github.com/openbot-coder/pytdxdata)可作为证券行情/板块数据适配候选；本次没有完成其行业资金定义、历史成份和日期口径验证，未接入生产评分。
- [同花顺公开行业表](https://data.10jqka.com.cn/funds/hyzjl/)直接HTTPS访问成功；未安装AKShare、未执行其验证脚本。即时、5日、10日各90行业、共6页270条，验证周期行业集合相同、无重复、字段和净额恒等式。
- [Tushare同花顺行业资金接口](https://tushare.pro/document/2?doc_id=343)要求账号及6000积分，当前没有相应凭据，未作为免费备用接入。

## 本机实测与边界

原参数和AKShare公开参数均返回RemoteDisconnected；本机未配置环境代理，不能因此排除网络或上游策略。没有尝试轮换IP、伪造验证或无限重试。

同花顺页面没有明确交易日期；HTTP Last-Modified是页面时间，不能充当交易时间。周期数值可以展示，但不得称为已核验的最新交易日数据。若各周期缺失、分页重复、字段变化、出现验证页或净额不符，保留旧缓存并明确标注，不补零，不发布半张榜单。

## 已落地

1. 东财push2单主机断连/429后立即停止重试，当前进程冷却至少10分钟；其它主机不受该冷却影响。冷却不是恢复保证，也不跨程序进程保存。
2. 失败记录包含主机、接口路径、请求次数、失败页码和已接收行业数量；不记录完整查询参数、代理地址或异常正文。
3. 周一常规更新自动刷新同花顺观察缓存；离线查看和缓存生成不联网。原始页面及采集时间在data/raw/ths归档。
4. HTML、Markdown和PDF统一增加同花顺观察；完整270条数据保存在同目录“同花顺行业资金.csv”。
5. 同花顺不参与东财评分或逐股大模型复核。股票行业映射和复核状态未因备用表而变更；后续要用于替代生产筛选，须先补独立行业成员映射、可靠交易日期和可比历史序列，再验证新规则。

## 验证

164项测试通过，包含新增10项连接冷却、页码诊断、单位、验证页拒绝、分页完整性、周期范围、缓存保护和展示转义测试。完整报告先暂存检查，再替换发布；旧报告在本次运行before目录保留。没有调用DeepSeek，也未调整投资权重。
