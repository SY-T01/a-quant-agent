# 行业优先与使用体验迭代

## 解决的问题

以前行业方向与个股分别排序，个股池没有限制在优先行业内；网页只展示6个行业、PDF只展示4个行业，而内部使用10个。用户难以理解行业与股票之间的关系。

现在只有本期全部优先行业内的公司可以进入主名单。网页、Markdown、PDF展示相同的全部行业，逐项说明选出了哪些公司，或为何未选出公司。行业外公司的规则评分即使更高，也只能进入单独的补充观察，不进入逐股复核和资金配置。

## 行业范围与分类

正式优先行业必须直接匹配至少3家已披露公司财报，再按持有期对应的行业分数排序，最多10个。缺少直接可比财报的细分板块单列为市场观察，不以同名、近似名称或父子关系推测公司归属。覆盖门槛用于避免极小样本或无财报板块被当成可落地选股方向，并非收益优化结果。

行业名单独立于个股估值排名，不反过来按想要的股票挑行业；主名单最多5只、每行业最多2只。不够5只时保留实际结果，不从行业外补齐。

## 选股解释

行业核验逐项记录财务增长公司数、进入行情池数、通过个股门槛数、实际入选名单与原因。原因包括暂无双增长盈利公司、资金方向不适用、现金流覆盖不达标、规模不达标、行情缺失/过期、估值超限以及数量与排序限制。一家公司可以命中多项原因，因此原因计数不能相加为公司总数。

主名单与补充观察分开采集和展示，行情请求优先覆盖主名单行业，再将剩余名额用于外围观察。主名单仍只在真实取得并通过时间检查的行情范围内筛选。发布时另行核对行业归属，任何主名单股票超出优先行业都会停止发布并保留旧报告。

新流程与优先行业范围参与模型结果匹配，旧模型意见只作历史参考，不自动迁移为本期有效批准。模型调用失败原因仍优先显示，不会被“流程变更”提示遮盖。

## 使用入口

保留原1—9菜单编号，新增10“一键更新并生成完整研究报告”，一次本地密钥输入后执行周更新流程，包括回归检查、归档、数据更新、选股及一次DeepSeek分析。没有额外第二次模型请求，不自动重试。密钥仅传给子进程，不保存到偏好文件。

首页分组展示常用操作、研究设置、文件维护，显示最新报告源时间、主名单、模型意见覆盖、外围观察与设置是否匹配，并提示下一步。查看报告仍可直接回车，不联网。菜单5直接打开最新报告所在文件夹。

网页增加行业、股票复核、资金分配、补充观察的页内导航；报告顶部显示实际资金偏好。股票复核表新增所属行业，规则门槛按本次持有期动态显示，不再固定写PE45等旧数值。

## 数据与更新

程序、缓存、偏好和报告继续留在外置磁盘项目目录。每周一任务使用同一份新流程，无需新增自动任务。本轮发布采用现有有效缓存重筛，不主动调用付费API；原正式报告保存在周归档的before目录，新的主名单需要按新范围复核。
