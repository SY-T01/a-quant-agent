# 条件情景分析

当前投资结论与条件情景分析分别保存。暂缓、否决、待复核都不阻止继续研究；分析本身不改变原结论，不加入最终通过名单。

每股展示重新考虑的条件、取消投资假设的条件、假设已持有时的退出复核条件，以及持有3至6个月的向好、中性、不利路径。下一次模型调用要求输出引用本股证据的完整情景分析。缺项或引用无效时，采用明确标注的程序框架，保留原模型结论；不把程序补充内容冒充模型意见。

现有报告不额外调用付费API。程序利用本股资料、原模型阻断项及反方理由组织分析，并提示可能由旧输入遗漏造成的行业缺失判断。下次请求必定包含所有候选股所属板块资料。

盈亏测算使用报告参考价，假设投入1万元并人为设定价格涨跌10%、20%。这只是算术敏感性，忽略费用、分红和整手限制，不作为收益预测、目标价、情景概率或止损线。

网页、Markdown与PDF共用同一份分析结果。每周更新会按新一期资料重新生成程序框架；有本期有效大模型情景时优先采用其分析。
