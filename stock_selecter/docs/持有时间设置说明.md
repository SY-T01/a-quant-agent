# 预计持有时间设置

打开股票研究助手.app，选择菜单8，输入1至24之间的整数月份。直接回车取消修改。设置保存在外置磁盘项目的configs/research_preferences.json；默认6个月。修改后立即使用现有缓存重筛并生成网页、Markdown和PDF，不调用付费API，也不更新行情。

|持有时间|现金流/增长/估值/行业资金权重|最低现金流利润比|供应商PE上限|PB上限|
|---|---|---|---|---|
|1—2个月|25/15/20/40|0.8|35|6|
|3—6个月|35/25/20/20|0.8|45|6|
|7—12个月|40/25/25/10|1.0|35|5|
|13—24个月|45/25/25/5|1.2|30|4.5|

行业优先研究排序也随期限变化。1—2个月的行业分数由80%近期资金观察分和20%盈利增长广度构成；3—6个月各50%；7—12个月分别25%与75%；13—24个月分别15%与85%。至少有3家披露公司的行业才计算广度得分。行业资料有限，分数仍是观察优先级，不是投资结论；长期研究方向可以包含近期流出的行业。

股票候选仍限定于盈利、营收利润同比增长且有有效行情的已有财务公司池。1—6个月要求行业5日与10日均净流入；7—24个月只要求10日净流入，减少5日波动的影响。行情新鲜度、财报日期、成交与风险名称等检查不随期限放宽。不同月数处于同一分组时，筛选规则相同，具体持有月数仍传入模型与报告。

这些参数是透明的初始研究假设，没有完成对应期限的收益验证。较长期研究需要多年经营与竞争力资料，当前单期财报与短期资金不能代替这些证据。PE仍是供应商口径，没有自动认定为独立核实的TTM估值。

每周更新、菜单2和菜单4读取保存的期限。命令行可使用--holding-months指定本次期限，不修改持久偏好。期限参与模型复核的证据匹配，更换期限后旧意见保留为历史，不沿用旧期限的买入批准。假设买入的价格敏感性计算不因持有期变长而虚构更高收益。

本地缓存可能只含原候选的部分行情与公告；需要更完整的新期限筛选时使用菜单2更新，再使用菜单4取得对应期限的模型分析。菜单8本身不触发付费API。
