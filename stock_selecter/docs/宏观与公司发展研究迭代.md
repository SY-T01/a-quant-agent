# 宏观与公司发展研究迭代

本轮把官方宏观与原始公司披露接入现有量化初筛、大模型反向复核和条件计划流程。没有新增模型自由编造资料的权限，也没有改变原来的投资评分权重。

## 已实际取得的数据

- 国家统计局：制造业PMI、新订单和生产指数，当前原文包含13个月观测；CPI同比和PPI同比。
- 中国人民银行：M2同比、社融存量同比，当前取得3期金融统计报告。
- 5只候选公司的公开业务概况，保留业务构成、数据期末提示和供应商属性。
- 巨潮公开索引核对证券代码后下载的5份半年度报告PDF，保留原始文件、标题、披露日期、SHA256与提取页码。本次未检索到可用的投资者关系记录，未用其他资料伪装。

实际宏观指标7项，公司资料5家，原始公告5份。全部存放在项目的外置磁盘data目录。每次报告中显示具体来源和发布时间；月度指标不会被伪装成每周都有新数值。

## 算法与大模型分工

宏观计算采用可复算规则：PMI与50比较，计算相邻期和3个月变化；分位仅基于本次已取得的观测月份。M2和社融展示增长变化，不把它们直接等同为货币政策宽松或收紧。CPI/PPI当前只有最新一期时不输出伪造的趋势或分位。利率以及其他宏观指标目前尚未接入。

公司公告采用BM25中文字符二元组检索，并对主营、发展战略、经营计划、经营风险标题加权，降低误选会计附注或目录的可能。可检索主题是业务与产品、发展方向、主要风险；缺少对应段落时不补造。算法检索命中不等于语义已独立核实，模型和人仍需结合原文审查。

行业宏观影响采用显式的条件传导映射。例如：金属材料需关注需求、库存和具体商品价格；全国PPI不能当作锂价。光伏需关注项目投资及海外需求；游戏行业不能主要依赖制造业PMI解释。映射是研究假说，不是估计出的因果关系或收益预测。

DeepSeek收到的资料包新增官方指标、发布日期、公司业务、已检索公告的短节选与PDF页码。它需要区分披露事实、管理层说法和自身推断，提供宏观综述、公司发展驱动和风险，以及乐观/基准/悲观三种情景的成立条件和跟踪指标。不得虚构目标价、盈利数值或情景概率。

这些输出按条目验证引用与结构；公司业务介绍必须引用该公司概况或披露，不能只引用宏观数据。无效的公司前景条目不会让其他公司的有效股票复核一起丢失。公司三情景尚未由模型定制时，报告明确标注为本地条件框架，不冒充模型分析。

## 与现有两级决策和周报衔接

1. 原量化初筛继续提供候选及财务、现金流、估值依据。
2. 自动更新同时刷新宏观原文、候选公司资料与公告索引；相同公告PDF可直接复用。
3. 大模型复核获得新增资料，允许因此暂缓、否决或有条件通过。新增宏观或公告证据会使旧复核失效，不能在新资料下沿用旧的“通过”。
4. 网页、Markdown和分享版PDF新增宏观、行业传导、公司介绍和三种情景。所有原始来源可点击或追溯，不显示密钥或技术JSON。
5. 每周一18:00的既有任务继续调用weekly，实时更新的enrich阶段会自动刷新这些资料，归档包含context清单。环境已有密钥时仅调用一次大模型；没有密钥则生成本地报告并标记股票待复核。

本轮实际下载与解析使用公开接口，没有调用收费AI。新宏观/公司前景输出已完成模拟接口验证，尚未用用户真实密钥验证模型输出质量。现在可打开助手选择“大模型逐股复核与买入计划”，对新增证据执行新一轮复核。

## 操作与存储

- 统一应用入口不变：股票研究助手.app。
- 正常“更新数据与周报”自动刷新新增资料。
- 仅更新宏观与公司资料：`python3 -B -m stock_selector.sector_research --context`。
- 单独抓取和校验资料、不生成报告：`python3 -B -m stock_selector.context_research --refresh`。
- 完全离线验证周报：`python3 -B -m stock_selector.weekly --cached`。
- 原始宏观：data/raw/nbs、data/raw/pbc。
- 公司资料：data/raw/eastmoney/company_profile。
- 原始公告PDF：data/raw/disclosures。
- 资料缓存：data/normalized/context_research/context.json。

## 本轮验收与限制

97项测试通过，覆盖表格列解析、数据水平和同比区分、发布日期边界、缓存未来数据剔除、BM25风险段落选择、未知引用拒绝、三情景结构校验、资料变化使旧意见失效，以及新增资料进入模型请求。当前47份被报告引用的原始快照校验通过。

发布日期与观察时间分别保存；历史宏观表格可能已修订，当前不是完整历史数据版本库，不能直接据此做无未来信息的历史收益回测。公司介绍中的宣传性表述不作独立认证，原始公告节选也不是整份报告的完整审计。3至6个月投资有效性仍需真实历史数据与样本外检验。
