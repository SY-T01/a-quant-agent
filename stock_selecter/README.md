# 股票研究助手

**已接入统一桌面入口：** 请优先打开同级 `A_stock/A-Quant.app`，在主窗口选择“选股研究”。研究数据、报告和偏好仍在本目录，原命令行及周更新入口保留。新增桌面功能和与日报的联动见 [整合版使用说明](../A_stock/INTEGRATION_GUIDE.md)。下文为原独立菜单的兼容说明。

上传到自己的GitHub可按 [GitHub上传指南](docs/GitHub上传指南.md) 操作。源码和配置示例纳入版本管理，个人资金偏好、行情缓存、AI存档与报告留在本机；建议先建立私有仓库。

当前软件版本0.8.0。主名单继续使用原可解释规则；优化方案的新因子作为并行研究，尚未自动替换选股模型。

双击 **股票研究助手.app**，在统一中文菜单中选择：

1. **查看最新报告**：直接打开已有报告，不联网；回车默认执行此项。
2. **更新数据与周报**：测试、归档、更新、生成新报告，失败时保留原报告。
3. **检查运行状态**：查看数据时间、覆盖和原始快照校验。
4. **DeepSeek解读**：本地输入密钥，使用一次API解读现有证据；配置资金后同时生成分配建议，密钥不保存。
5. **打开报告文件夹**：查看历史周报和导出文件。
6. **重新处理已保存的AI结果**：使用正文存档，不收费。
7. **导出分享版PDF**：导出当前报告，无需重新抓取数据或调用AI。
8. **调整预计持有时间并重新筛选**：输入1—24个月，保存偏好并用本地缓存重新生成分析，不调用付费API。默认6个月。
9. **设置计划资金与分配风格**：输入例如100000或10万，选择保守、均衡或积极。设置后选菜单4，让DeepSeek按本次资金和持有期生成分配。
10. **一键更新并生成完整研究报告**：本地输入密钥，自动检查、归档、更新资料、行业内选股，并在一次DeepSeek调用中生成复核和资金方案；失败不自动重试付费API。
11. **数据审计与增强因子观察**：离线检查资金归一化、相对沪深300、市场宽度、行业层级与财务质量的覆盖；下载因子与财务核对明细，不调用AI。
12. **前瞻跟踪与策略验证状态**：查看实际生成后的5/10/20交易日等待、受阻和到期样本，不回填历史预测，不自动下单。

应用会打开一个终端中文菜单；不是另行安装的桌面软件。退出菜单输入0。若Mac限制打开，可右键应用选择“打开”；也可以在本目录终端运行 `python3 -B -m stock_selector.launcher`。

首页按“常用操作、研究设置、文件与维护”分组，显示当前偏好、报告时间、主名单/外围观察数量和下一步建议。原菜单编号保留。首次使用可先设置8和9，再选10；日常看报告直接回车，已有新鲜数据只需AI解读时选4。

每周一18:00的既有自动任务继续使用原来的后台流程，无需打开菜单。运行时需保证电脑环境和外置磁盘可用。

程序用于研究和条件初筛，各持有期限的评分参数尚未完成样本外收益验证。详细方法、数据覆盖和限制见docs中的指南与自评。

## 两级复核流程

规则量化初筛 → DeepSeek逐股反向复核 → 最终条件计划。应用选择“大模型逐股复核与买入计划”运行第二阶段。大模型可否决或暂缓，未复核股票不会进入最终买入名单。周报展示两级结论与分歧、开始/分批/取消/退出条件。每周一更新若已有环境密钥会调用一次，否则明确标为待复核；本地缓存验证不调用收费API。

报告生成时自动附带中文分享版PDF，位于 `reports/sector_research/行业研究周报.pdf`，网页顶部也提供下载入口。

宏观与公司研究现包含统计局/央行指标、公司业务概况、原始公告检索及三情景分析接口，自动随周报更新。详见 `docs/宏观与公司发展研究迭代.md`。新增证据需要重新运行大模型复核；旧意见不会自动被视作本期有效结论。

持有时间会调整行业研究优先级、股票评分权重、现金流和估值门槛，并传给DeepSeek和条件情景分析。每周一沿用保存的偏好。调整期限后的本地重筛仅使用已有行情与公告覆盖；选择菜单2可刷新资料，菜单4可按新期限付费复核。设置保存在本项目 `configs/research_preferences.json`。详见 `docs/持有时间设置说明.md`。

资金分配包含当前条件方案与未来备选方案，二者是同一笔钱的不同情景。当前方案只纳入有条件通过股票；暂缓股票可在备选方案中说明解除阻断后的比例。报告列出个股预留金额、现金及通过股票的分批预算。分配与金额、风格、期限、证据匹配，程序核对总额和集中度，不自动下单。详见 `docs/计划资金分配说明.md`。

当前选股严格按“优先行业 → 行业内公司 → 大模型复核 → 资金分配”。正式优先行业要求至少3家直接匹配的已披露公司；财报映射不足的细分板块只作市场观察。网页、PDF与Markdown统一展示全部优先行业、入选公司和未入选原因。行业外公司的分数再高也只列补充观察，不补位、不参与主名单资金分配。详见 `docs/行业优先与使用体验迭代.md`。

本轮按上传的优化方案加入了独立行业价格/成交额通道、5/10/20日RS与真实分母归一化、同层级缩尾分位、增强分完整性检查、扣非利润与投资收益核对、费用及可交易性约束下的前瞻观察和滚动分窗框架。多年历史成分、完整市场宽度和多模型样本外对照尚未完成。评估结论、适用边界与数据字段见 `docs/优化方案评估与迭代.md`。
