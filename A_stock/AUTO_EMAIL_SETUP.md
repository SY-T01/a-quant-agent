最新操作入口为`./run.sh menu`。当前实际配置是交易日14:00；启动命令`./run.sh watch`会占用当前终端，Ctrl+C停止。同一目录只允许运行一份本版本任务。另一个终端可用`./run.sh watch-stop`请求停止，再用`./run.sh watch-status`确认；API/网络调用未返回时可能需要等待，发信已经开始后不能保证撤回。

`./run.sh doctor`不联网检查配置；`./run.sh offline-preview`不调用模型或邮件。`./run.sh watch-recover`恢复中断分析，发送结果未知的邮件仍须核对，不能自动重投。首次升级前请先停止旧代码实例，新实例锁不能识别未使用锁的旧代码。

目标流程：代码或名称检索 → 自动下载并更新历史数据 → 计算均线、动量、回撤和波动 → DeepSeek综合判断 → 自动发邮件并保存报告。

目前已有完整串联代码，默认跟踪159567，每交易日14:20发送一次。新增股票用type=stock，场内ETF用type=etf。不支持所有场外基金类别。名称不能唯一匹配时停止，不随意选标的。每次全量更新前复权历史，以处理复权值可能变化的情况；同一报告日及同一数据日期成功发送后不重复分析或投递。

## 第一步 本机填写配置

在项目目录执行：

```sh
./run.sh watch-setup
```

按提示填写DeepSeek密钥、发送邮箱SMTP服务器、登录邮箱、SMTP授权码、发件邮箱、收件邮箱及账号可用模型。密钥输入不回显。无需将密钥发到聊天。当前SMTP支持SSL模式，端口465；587 STARTTLS尚未实现。

本机密钥文件为runtime/watch-secrets.json，仅当前用户可读写。文件未加密，应仅存于受信任的本地磁盘，已被.gitignore排除。跟踪列表和发送时间在runtime/watch-config.json；不应将密钥写入该公开配置。

## 第二步 手动验证一次整条流程

```sh
./run.sh watch --once
```

此命令会联网下载、向DeepSeek提交公开行情指标并产生API费用、将最终日报发送到配置的收件邮箱。不输出分析正文到终端；保留本地JSON、文本和HTML。若只想调用模型并保存报告而不发信：

```sh
./run.sh watch --once --preview
```

preview仍产生DeepSeek API费用。没有密钥或SMTP配置时不能验证真实邮件交付。SMTP accepted表示服务器接受，不保证进入收件箱。失败或unknown状态需核查，不自动重投。

## 第三步 持续运行

```sh
./run.sh watch
```

默认在每个内地交易日北京时间14:20开始运行一次。程序每30秒检查；更新数据、分析后发信，并非保证14:20整点进入收件箱。当天运行成功后不再重复。电脑必须开机、联网且程序持续运行，Ctrl+C停止。关闭终端或休眠期间不会运行；错过发送时间15分钟后不补发过期建议。当前未安装系统开机常驻服务。

当前可以在上午或下午发出日频策略建议，但数据仍为此前最近已完成交易日，并非实时盘中判断。14:20报告会显著注明行情截止日；真正基于当日行情决策仍需可靠的分钟数据。发送时间与数据新鲜度是两回事。18:00前使用此前最近已完成交易日；若改为盘后发送则必须取得当天完整日线。

## 数据检查及故障处理

### 录入或修改持仓

运行`./run.sh positions`，按提示输入代码、类型、持有份额及券商成本；也可双击项目中的`录入持仓.command`。无需编辑JSON。成本最多保留4位小数，数量填0表示已清仓。每次填写代表替换当前持仓快照，不是追加买入。

查看已保存数据：`./run.sh positions list`。当前持仓和修改历史保存在自动日报目录的`positions.sqlite`，不同于真实资金成交账本。每日新报告会读取最新持仓，在邮件中显示份额、成本及按录入成本计算的总额，不会重新发送已经发出的同日邮件。

成本和数量目前留在本地，不提交给DeepSeek；DeepSeek继续综合公开量化指标。资金、可卖数量和ETF执行规则未核对前不产生具体交易股数。未获得未复权估值价格前不以复权研究价计算盈亏。收到成交后请及时更新持仓。

不调用模型、不发信的公开数据检验：

```sh
./run.sh watch-check --config config/watch.example.json
```

交易日历及名称列表每日缓存。日线有重复、无效价格、少于61条或末条日期落后于应有交易日时暂停推荐。模型失败不会静默使用规则假装综合分析。数据或模型失败后冷却15分钟，每数据日最多尝试3次；API客户端每次最多请求2次。发信结果未知或进程在处理中退出时，不自动重发，须人工核查SQLite状态及邮箱。

免费公开数据接口可能限流；限流期间不要密集重试。长期稳定运行仍需评估可靠数据供应方。程序不会根据下载失败时留下的旧CSV生成“今日建议”。

所有任务状态记录在runtime/watch/watch.sqlite。日报文件在runtime/watch；历史行情在runtime/watch/data。尚未录入个人资金和账户时只提供方向性研究判断，不生成买卖份数。当前未自动采集资讯、净值和折溢价，明确作为缺失项提交给DeepSeek；不能让模型编造补齐。
