# A-Quant 0.4.0：统一选股与持仓研究

现在以 `A_stock/A-Quant.app` 为统一桌面入口。打开主窗口，左侧选择 **选股研究**。原有持仓、日报、邮件、来源轮换和菜单栏继续使用。

如果软件此前已经打开，请从右上角菜单选择“退出 A-Quant”，等待任务停止后再双击应用。窗口红色关闭按钮只会收起窗口。重开后，如需继续自动日报，手动点击“启动自动日报”。升级不会自动启动日报、调用模型或发信。

## 使用流程

1. 在“选股研究 → 研究设置与任务”确认预计持有月数、计划新增资金和风格，点击“保存研究偏好”。预算支持 `10万`，留空可取消资金设置；已有持仓不包含在这笔新增资金内。
2. 已有缓存时点击“本地重新筛选”；需要新资料时点击“更新数据与周报”。这两个操作都不调用付费模型。
3. 按需点击“DeepSeek 复核（计费）”，或“更新并复核（计费）”。共用“设置”页的密钥和模型，不重复保存密钥，不自动重试付费调用。
4. 在“候选与复核”查看主名单、外围观察、规则分及模型意见。双击股票查看依据、风险和条件计划；“打开完整周报”可查看原来的完整网页报告。
5. 选中股票，点击“加入日报关注”。暂缓股票也可以关注，用于后续观察；加入关注不会记为买入。修改关注前需停止自动日报，保存后重新启动。关注上限沿用20个，重复添加不会重复计入。
6. 实际买入后，到“我的持仓”录入券商显示的股数和成本。

“行业与资金”展示优先行业及当前、未来备选的资金方案。两种方案是同一笔资金的替代情景，不可相加使用。历史或设置不匹配的方案会明确标注。

研究操作页还提供已有模型结果重放、PDF 导出、数据检查、增强因子审计和前瞻验证。日志与进度在窗口内显示；后台研究期间可以查看其他页面。关闭窗口继续研究，退出应用会停止本软件启动的研究任务及其子任务。其他终端启动的任务不会被接管。

## 研究与日报的联动

普通股票日报会读取现有的选股研究报告，重新校验候选证据及模型意见，并同时传给日线模型。只有进入行业内主名单、具有有效的本期有条件通过意见、研究数据通过时间检查且研究设置匹配时，才保留日线模型产生的新增买入倾向。暂缓、否决、待复核、外围观察、研究不可读或历史意见都会将新增买入倾向改为观望；卖出或减仓倾向仍可保留。

有条件通过不代表买入条件已经实现，仍需人工核对。日报会显示研究数据时间和复核意见。ETF 继续使用原有日线研究流程。提交给模型的新增字段仅来自公开研究，不包含新增资金预算、真实持仓数量或成本。

研究页面始终显示报告生成时间和行业数据截止时间；生成了新文件不代表取得了新行情。当前已有行业报告曾因接口失败回退到旧缓存，需在完整周报中核对其限制。原有评分规则和资金风格仍是待验证的研究假设，本次整合不代表已完成收益验证。

## 数据与兼容

- 应用、持仓、密钥、日报状态继续位于 `A_stock` 原位置。
- 研究程序、数据、偏好和正式报告继续位于同级 `stock_selecter`；不复制第二份业务数据库。请同时保留两个目录。
- 新窗口研究操作与原每周更新共用 `data/weekly.lock`，避免同时发布。请勿同时在旧终端菜单执行手动重筛或模型复核。
- 本地重筛和单独模型复核先生成暂存报告，验证后再发布；失败不会覆盖正式报告。上一版存入 `stock_selecter/reports/desktop_runs`。周更新沿用 `reports/weekly` 的归档与回退流程。完整更新遇到模型失败时，数据部分可能已经发布，界面会报告模型未完成。
- 新桌面研究日志在日报状态目录下的 `research/desktop-research.log`，文件仅当前用户可读写。
- 保留原 `stock_selector.launcher` 命令行和每周任务入口。没有新增自动化任务，也没有修改已有发送时间。

本次修改前的应用启动器和相关源码备份在 `A_stock/runtime/integration-backup-20261112`。自动验证输出在 `A_stock/runtime/integration-qa`，窗口验证图片在 `A_stock/runtime/desktop-qa`。

当前仍是依赖本机源码和 Python 环境的应用，不是可在另一台电脑直接安装的独立软件包。
