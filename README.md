# 股票研究与持仓助手

统一应用入口：双击 **A_stock/A-Quant.app**，从右上角 A 图标打开主窗口。

- **选股研究**：行业初筛、公司候选、模型复核、研究资金、报告与前瞻验证。
- **我的持仓**：录入实际持仓与成本。
- **总览**：启动或停止日线日报、手动生成并发送邮件。
- **设置**：共用模型、密钥和邮箱配置。

使用方法见 [整合版使用说明](A_stock/INTEGRATION_GUIDE.md)。升级后请完整退出旧窗口再重新打开；自动日报按需手动启动。

请同时保留 `A_stock` 和 `stock_selecter` 两个目录，现有数据分别沿用原位置。打开应用不会自动调用付费模型或发送邮件。

源码备份和 GitHub 上传见 [上传说明](GITHUB_GUIDE.md)。源码仓库不包含本机运行资料和编译好的应用；下载后请按说明重建环境与应用入口。
